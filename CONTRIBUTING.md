# Beiträge zum Projekt

Fehlerberichte und Vorschläge können über GitHub-Issues eingereicht werden.
Beschreibe Version, Schritte, erwartetes und tatsächliches Verhalten; verwende
anonymisierte Projekte. Sicherheitslücken bitte nach `SECURITY.md` melden.

Für Änderungen: Branch anlegen, relevante Tests ausführen und Pull Request mit
kurzer Beschreibung und Prüfungsergebnis erstellen. Buildinformationen stehen
im README und unter `docs/`. Windows und das in `global.json` festgelegte SDK
werden für die WPF-Oberfläche benötigt.

Reiche nur Code und Material ein, für das du die nötigen Rechte hast. Beiträge
zum eigenen Projektcode sollen unter dessen MIT-Lizenz nutzbar sein.
Neue Fremdabhängigkeiten benötigen Original-Lizenztexte, genaue Versionsbindung
und einen aktualisierten Lizenzbericht. Keine Geheimnisse, privaten Schlüssel,
Herstellerpakete ohne Vertriebsrecht oder produktiven Daten einchecken.
