# Optionaler lokaler cab-Handbuchtest

Diese fest gebundenen Python-Werkzeuge dienen ausschließlich der lokal aktivierten
PDF-Extraktion. Ihre Original-Lizenztexte sind mit Dateihashes in manifest.json
belegt. Es werden keine Paket-Binärdateien, Hersteller-PDFs oder Herstellerbeispiele
mit der Anwendung ausgeliefert. Installation bei Bedarf in eine eigene Umgebung
mit build/requirements-cab-manual.txt; keine automatische Installation durch Tests.
